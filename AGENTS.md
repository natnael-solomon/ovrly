# Agent instructions

## Before making changes

- Read every `.md` file in the repository before modifying code, committing, pushing, or creating/updating a PR. Re-read files added or changed while working.
- Inspect existing code and local changes. Follow established patterns and preserve unrelated work.
- Ask before significant scope or behavior changes.

## While working

- Make focused changes. Reuse existing helpers and dependencies; avoid unrelated refactors or formatting.
- Keep credentials, personal data and local artifacts out of Git.
- Keep private references out of public artifacts.
- Update documentation when behavior or setup changes.

## Before handing back

- Run the relevant tests, build and lint checks. Review the final diff.
- Report what changed, failed checks and unverified behavior. Claim a check passed only when it did.

## Git and external actions

- Follow `WORKFLOW.md` for branches, commits and PRs.
- Do not list AI assistants or agents as commit authors or co-authors, including AI `Co-authored-by` trailers in squash messages.
- Do not commit, push, merge, publish or deploy without authorization.
- Do not discard changes or rewrite history without explicit approval.
