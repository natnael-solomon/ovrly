# Agent instructions

## Before making changes
- Read WORKFLOW.md and the relevant README.
- Inspect existing code and follow established patterns.
- Check for local changes; never overwrite unrelated work.
- Ask before making significant scope or behavior changes.

## While working
- Make focused changes that address the requested task.
- Prefer existing helpers and dependencies over adding new ones.
- Keep unrelated refactors and formatting changes out of the diff.
- Never add credentials, personal data or local artifacts to Git.
- Update relevant documentation when behavior or setup changes.

## Before handing back
- Run the relevant tests, build and lint checks.
- Review the final diff for unintended changes.
- Summarize what changed and report failures or unverified behavior.
- Never claim a check passed unless it was actually run successfully.

## Git and external actions
- Follow WORKFLOW.md for branches, commits and pull requests.
- Do not commit, push, merge, publish or deploy without authorization.
- Do not discard changes or rewrite history without explicit approval.
